# 📁 public/models

This folder contains the local browser-based AI models and neural network weights required for live facial tracking.

⚠️ **Deployment Note:** Due to GitHub's 25MB file-size upload constraints for browser interfaces, these heavy model binaries are excluded from the online repository registry. 

### 🔧 Local Setup Instructions:
To run this project locally, ensure you copy the pre-existing `models/` folder directly from your local development machine back into the `frontend/public/` directory before starting the application server.
