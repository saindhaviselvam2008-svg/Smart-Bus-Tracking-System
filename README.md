# 🚌 Smart Bus Tracking System

A smart transportation management system developed to help students track buses in real-time, mark attendance using facial recognition, receive immediate emergency alerts, and manage lost & found items seamlessly.

---

## 🚀 Features

### 📍 Live Bus Tracking
* Real-time bus route monitoring and live location tracking.
* Driver details and pathing route information.
* Seat occupancy tracking to monitor capacity.

### 📸 Face Recognition Attendance
* Automatic attendance marking using computer vision.
* Real-time face recognition integration.
* Bus-wise digital attendance records and history logs.

### 🚨 SOS Emergency Alert
* Instant emergency alert system pipeline.
* Real-time parent notification support via automated messaging.
* Centralized admin monitoring dashboard for campus safety teams.

### 📦 Lost & Found
* Portal to report lost personal items quickly.
* Ability to upload item images for verification.
* Track item status seamlessly (Pending / Found).

### 😴 Sleep Alert
* Destination-based alerts for commuting students.
* Wake-up reminders before arrival at designated stops.

### 🗺 Campus Map
* Campus navigation support for blocks and entry points.
* Easy location access for all transit bays.

---

## 🛠 Technologies Used

### Frontend
* React.js (Vite)
* Tailwind CSS
* Firebase Realtime Database

### Backend & Core Services
* Python (Flask / OpenCV / Face Recognition)
* Node.js (Express & Twilio Gateway Integration)
