🚌 Smart Bus Tracking System
A smart transportation management system developed to help students track buses in real time, mark attendance using face recognition, receive emergency alerts, and manage lost & found items.

🚀 Features
📍 Live Bus Tracking
Real-time bus route monitoring
Driver details and route information
Seat occupancy tracking
📸 Face Recognition Attendance
Automatic attendance marking
Face recognition integration
Bus-wise attendance records
🚨 SOS Emergency Alert
Emergency alert system
Parent notification support
Admin monitoring dashboard
📦 Lost & Found
Report lost items
Upload item images
Track item status
😴 Sleep Alert
Destination-based alerts
Wake-up reminders before arrival
🗺 Campus Map
Campus navigation support
Easy location access
🛠 Technologies Used
Frontend
React.js
Tailwind CSS
Firebase Realtime Database
Backend
Python
Flask
OpenCV
Face Recognition
