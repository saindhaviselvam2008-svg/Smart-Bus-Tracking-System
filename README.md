# 🚌 Smart Bus Tracking System

A comprehensive smart transportation management platform designed to enhance student safety, streamline attendance tracking, and improve the overall campus transportation experience through real-time monitoring and intelligent automation.

---

## 📖 Overview

The **Smart Bus Tracking System** is an innovative solution developed to address common challenges faced in institutional transportation systems. The platform enables students, parents, drivers, and administrators to interact through a centralized system that provides real-time bus tracking, automated attendance management, emergency support, and digital lost & found services.

By integrating Artificial Intelligence, Computer Vision, and Real-Time Tracking technologies, the system transforms traditional transportation management into a safer, smarter, and more efficient ecosystem.

# 🏗 System Architecture

The system is built using a modular architecture consisting of:

### Frontend Layer
Handles user interaction, tracking dashboards, attendance displays, and navigation interfaces.

### Backend Layer
Processes requests, manages data flow, and coordinates communication between system components.

### AI Module
Performs facial recognition and attendance verification using computer vision techniques.

### Database Layer
Stores user information, attendance records, bus details, and lost item data.

# 🚀 Installation Guide

## Clone the Repository

```bash
git clone https://github.com/saindhaviselvam2008-svg/smart-bus-tracking-system.git
```

## Navigate to Project Directory

```bash
cd waypoint
```

## Frontend Setup

```bash
cd waypoint
npm install
npm start
```

## Backend Setup

```bash
cd ai-backend
pip install -r requirements.txt
python app.py
```
